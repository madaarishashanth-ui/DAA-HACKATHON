DAA Core Analysis: Sorting & Searching

Merge Sort (Divide-and-Conquer)

Divides the array into two halves recursively until singleton subarrays are reached, then merges the sorted halves into an auxiliary buffer. Guaranteed $O(N \log N)$ worst-case time complexity and stable sorting, requiring $O(N)$ extra space.

Recurrence: T(n) = 2T(n/2) + \Theta(n) \implies O(n \log n)

Quick Sort (Partition-Exchange)

Selects a pivot element and rearranges elements such that elements smaller than the pivot precede it, and larger elements follow it (Lomuto partitioning). In-place with $O(\log N)$ call-stack space. Average $O(N \log N)$, worst-case $O(N^2)$ when pivot selection is degenerate.

Recurrence (Balanced): T(n) = 2T(n/2) + \Theta(n) \implies O(n \log n)

Binary Search (Decrease-and-Conquer)

Operates strictly on pre-sorted arrays. Repeatedly evaluates the middle element (`mid = \lfloor(low + high)/2\rfloor`). If target matches, search terminates. Otherwise, half of the search interval is discarded immediately, delivering an optimal $O(\log N)$ search complexity.

Recurrence: T(n) = T(n/2) + O(1) \implies O(\log n)
